## 執行架構

- Pyto 的 `ios_host`、Metal／UIKit 包裝與 Python 執行緒迴圈由 Godot 場景、渲染及物理迴圈取代。
- 地形目前載入完整單一世界。大型生態開始移植後再加入原來的 chunk 活動範圍、離屏休眠與受控更新預算。
- 移動先使用 Godot CharacterBody2D；三分層地形使用 TileSet 碰撞。特殊流體與熱傳不能直接假設引擎物理會自動模擬。
- 桌面及 iOS 初期共用 GDScript。只有 profiling 證明瓶頸後才考慮 GDExtension；新增原生庫會增加 iOS 編譯與 Xogot 相容工作。
- `assets/converted` 保存基礎 PNG，`assets/animated` 已加入 4,052 個原動畫影格的圖集；角色與生物基礎動畫已接線。地下與次世界背景圖元已接入，專屬戰鬥 VFX、特殊招式與完整動畫綁定仍待移植。
