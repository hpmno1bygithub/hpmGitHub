# PytoRPG Godot 0.3.0 — 操作、選單、直式注音與武器

解壓 Phase3 ZIP，在 Godot 4.5.1 匯入 `project.godot`，等待匯入後按 F5。這是可繼續開發的專案，尚非完整 FIX131 等價移植。

## 這次更新

- 國字右側直式注音，聲母／介音／韻母由上至下；二、三、四聲在右，輕聲在上。題目與四個選項都使用同一排版。
- 梯子以身體與腳部判斷，修正頂端提早離開攀爬、無法由平台向下進入梯子。原生與自訂單向平台使用獨立碰撞層，下鍵可以穿越；實心地板不會被關閉。
- 預設就是跑速 235，保留加減速。翻滾速度 355、持續 0.38 秒；蹲姿速度 55%、趴姿 35%。使用原角色的蹲、爬行與翻滾動畫，以及對應碰撞尺寸。
- 蹲／趴可按上站起，低天花板會阻止站起。趴下時敵人不會追擊或主動接觸攻擊；蓄力及攻擊期間會暴露。
- 啟動先顯示新開遊戲、載入遊戲、遊戲設定。有進行中的遊戲時可繼續冒險；新遊戲覆蓋前有確認。設定可切換觸控按鈕與習題頻率。
- 8 種武器可持握、裝備及使用：鐵劍、獵刀、長矛、巨斧、鐵鎚、巨劍、甩鞭、能量弓。近戰使用原傷害、距離、冷卻、蓄力門檻、重擊倍率與目標上限；巨劍重擊有劍氣，能量弓有能量箭／蓄力箭雨。加入揮擊光弧、蓄力環、飛行軌跡與命中火花。

## 操作

| 按鍵 | 功能 |
|---|---|
| A/D、←/→ | 跑步（含加減速） |
| Space | 跳躍 |
| Shift 或 K | 翻滾 |
| C | 蹲下，再按趴下；蹲／趴間切換 |
| Z | 趴下／站起 |
| W／↑ | 蹲趴站起、向上攀爬 |
| S／↓ | 下梯、下單向平台；實心地面蹲／趴切換 |
| J | 短按放開普攻；按住蓄力、放開重擊 |
| E | 寶箱／傳送門互動 |

觸控提供同樣的移動、上下、蹲、趴、滾、跳、武器及互動按鈕。背包中的「開發測試：領取 8 種已實裝武器」可取得本次測試用武器，再從上方「裝備武器…」選擇；此操作會存入背包，不是原版獎勵流程。原寶箱與掉落也能取得武器。

新遊戲／載入後會進入原有暖身答題。預設各類 2 題，完成才能出發。主畫面「探索地點…」仍是開發用快速跳點。

## 存檔與更新

沿用相同專案名稱，`progress_v2.json` 增加已裝備武器欄位，舊第二階段存檔可由選單載入；第一階段存檔仍保留相容入口。新開遊戲只重設冒險，獨立學習進度保留。`settings_v1.json` 儲存觸控顯示設定。第一次開啟停在選單不會自動覆寫遊戲存檔。

保留 Phase2 資料夾，Phase3 解壓到另一資料夾並匯入新的 `project.godot`，避免誤開舊版。不要變更專案名稱／iOS Bundle ID，以免改用另一份使用者資料區。

## 驗證與仍待移植

Windows Godot 4.5.1 已執行匯入、原 smoke／gameplay 測試，以及 `tests/phase3.gd`：梯頂交接、平台下穿、下梯、跑速／減速、翻滾／姿態恢復、低天花板、趴下敵人偵測、弓箭傷害／薄牆碰撞、選單暫停、新遊戲重設、讀檔恢復裝備。另已擷取並檢查實際選單、直式注音及蹲趴畫面，見 `docs/phase3-*.png`。
