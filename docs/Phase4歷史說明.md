# PytoRPG Godot 0.4.0 — 互聯編輯器與遊戲系統

在 Godot 4.5.1 匯入本資料夾的 `project.godot`，等待匯入後按 F5。首次進入顯示開場選單。本版回應地形背牆、蹲姿重播、原版武器特效、編輯器互聯、兩項設定與背包／流體需求。**本版仍不是原 FIX131 所有系統的完整等價移植**；已實作與未完成項目逐項列在 [移植驗收與差異](docs/Phase4移植驗收.md)，不以素材匯入率當玩法完成率。

## 先驗收這些操作

1. 「遊戲設定」有死亡懲罰、預設物品及觸控顯示。原版死亡關閉的意思是保留最後 1 HP；預設物品只影響新遊戲，關閉仍保留原版鐵劍與鉤爪，開啟另給 6 種穿戴裝備。
2. 新開遊戲／載入後完成暖身習題。A/D 跑步，Space 跳，Shift/K 翻滾，C 蹲／趴切換，Z 趴／站起，W/↑ 站起或上梯，S/↓ 下梯／下平台。蹲姿動畫播完後保持，不會重播起立動作。
3. J 按住蓄力、放開攻擊。扣血與特效依原素材 action/effect 影格事件触發；素材編輯的事件會影響實際招式時間。E 互動；F 採集前方分層圖塊、搭配上下鍵改方向；Q 鉤爪向前上方射出／取消。觸控提供「採」「鉤」。
4. 打開背包：72 格、3 頁、分堆／合併／整堆交換、指定數量丟出、裝備與放置素材。重擊次數逐把保存。背包滿時剩餘掉落保留；寶箱剩餘物品落在原地。開發測試武器按鈕供本次驗收，不屬於正式獎勵流程。
5. 前景採集後會留下同材質背牆；可透過地圖編輯器另外清除或繪製背牆。液體按分層圖塊剩餘容量流動，蜂蜜比水黏稠，岩漿會接觸傷害與燃燒，水能熄火／冷卻岩漿。沼澤是原版 hazard 地形，會造成持續傷害。

## 兩個互相連動的編輯器

開場選單有「地圖編輯器」與「素材／動畫／特性編輯器」；遊玩中點「編輯」也能進入。

- 地圖：前景、背景牆、原生 1–7 分層遮罩、自訂素材、水／岩漿／蜂蜜、沼澤、生物放置／移除；左鍵或觸控繪製，右鍵清除，按鈕平移，支援復原／重做。
- 素材：像素畫筆、透明橡皮擦、筆畫復原、動畫預覽、複製／刪除影格、FPS、循環、action/effect 事件。武器可選原版 FIX54 圖元特效或自訂特效影格。
- 生物／魔物：修改生命、傷害、速度、碰撞尺寸、敵對特性；動作表提供啟用、距離、速度、傷害、持續時間、冷卻、機率與優先級。已支援的動作會讀取相同 ID 的動畫事件。
- 自訂圖塊：可選 solid、platform、ladder、climb_platform、passable，保存後更新地圖實際碰撞與動畫。
- 複製新素材需使用同類別 ID，例如 `creature.my_wolf`；會複製像素／動畫與生物定義／動作資料。新武器可用「領取並測試此武器」，新生物與自訂圖塊可在地圖選单放置。

修改後點「儲存並套用」或「保存地圖並套用」。資料按 ID 關聯，修改一份素材會更新所有使用它的實例。新功能尚有邊界，請參考驗收表，特別是未移植的特殊 Boss 招式。

## 後續在 Godot 開發

工作台「匯出內容包」輸出 JSON。回到 Godot 編輯器右側 **PytoRPG** 面板，選「匯入遊戲編輯器內容包」，會驗證並合併到 `data/content_pack.json`，原檔保留 `.bak`。將內容包與 GDScript 提交 Git，即可沿用 GitHub Actions 打包。流程與資料分層見 [Godot 開發與內容包](docs/Godot開發與內容包.md)。

執行中的編輯會寫到 `user://content_pack.json`，不直接覆寫原始地圖。此本機內容包的優先順序高於專案內容包；整合進 Git 後若要測試乾淨發行版，需備份並移走本機內容包，避免舊覆蓋仍生效。

## 存檔及驗證

沿用專案名稱與 `progress_v2.json`，可讀取 Phase2／Phase3 的背包彙總資料，轉換為 72 格；新增 backpack、穿戴、逐把重擊次數、液體與採集圖塊變更。學習進度與設定獨立保存。請保留舊 ZIP 與存檔備份，不要改專案名稱／Bundle ID。

Windows Godot 的原地圖與碰撞、習題與戰鬥、梯子與姿態，以及新增背包／流體／互聯編輯測試已執行。`tests/phase4.gd` 專門檢驗蹲姿停止重播、背牆、最後 1 HP、預設物品、分堆耐久、水量守恆、液體容量、內容包、克隆生物與動作事件。實際渲染截圖在 `docs/phase4-*.png`。

**iPhone／iPad 實機、Actions 雲端打包與覆蓋更新安裝仍未驗證。** 工作流程已接上本版測試，但不能把 Windows 通過說成 iOS 通過。原部署指南保留於 `docs/iOS與更新指南.md`。
