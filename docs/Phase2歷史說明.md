# PytoRPG Godot 0.2.0 — 第二階段玩法移植

在第一階段可開啟、移動的基礎上，這一版接上背景、生物／魔物、自訂素材、基礎戰鬥、寶箱／掉落、傳送門與算術／注音習題。**仍不是完整 FIX131 等價移植**；特殊技能、完整生態／流體與裝備系統繼續保留在移植清單。

## 開啟與這次怎麼玩

1. 解壓 Phase2 ZIP，在 **Godot 4.5.1 標準版**匯入 `project.godot`，等待新增動畫素材匯入後按 **F5**。
2. 依原版流程，進入遊戲先做暖身：預設乘法 2 題、加減法 2 題、注音 2 題，完成後按「繼續遊戲」。
3. 左上「探索地點…」可直接前往草原生物區、自訂魔物與寶箱區、武俠竹林，方便本次驗收。此選單是移植開發捷徑，原傳送門也已能使用。
4. **A/D 或左右鍵移動、Space 跳、Shift 跑、W/S 梯子、J 揮劍、E 開寶箱／進傳送門**。手機已有對應觸控按鈕；「劍」攻擊、「用」互動。
5. 靠近掉落物會拾取；左上「背包」查看。現階段使用鐵劍，其他武器可收進背包，但特殊技能與裝備切換尚未接上。
6. 「習題」可主動練習。答題會暫停整個遊戲，死亡後也會進入練習，完成後回出生點。預設遊玩 3 分鐘再次練習，可選下回合每類 5 題／15 分鐘或 10 題／30 分鐘。

## 這次實際接上的內容

| 功能 | 已接上 | 還有差異 |
|---|---|---|
| 背景 | 區域天空／山影，原地下與次世界的分層背景圖元及視差；9 世界可切換 | 地表植物的部分程序式圖形採簡化重建，非原畫面逐像素還原 |
| 生物與魔物 | 153 種定義，9 世界共 472 個實例；主世界 298 個，包含目前的自訂放置點 | 自然生物沿用附件快照位置，沒有重建完整生態生成與特殊 AI |
| 動畫 | 222 份動畫資產、4,052 個原影格，角色走／跑／跳／爬與生物移動 | Boss 專屬攻擊動畫、骨架綁定、招式 VFX 未完整接上 |
| 自訂素材 | 主世界 53 格、金字塔 10 格；依原 role 區分實體／單向平台／梯子／可穿越 | 自訂背景登錄有名稱但附件沒有對應像素檔，使用程序式背景 |
| 戰鬥 | 鐵劍原傷害 34、冷卻 0.30 秒；敵人追擊／接觸傷害、血條、受傷、死亡與重生 | 重擊、魔法、遠程攻擊、Boss 特例、元素反應未等價移植 |
| 掉落／寶箱 | 擊敗生物依原 loot 表掉落、靠近拾取、自訂寶箱只領一次、背包列表 | 尚未有完整裝備／消耗品／合成介面 |
| 傳送門 | 原 metadata 的目標地圖、對應入口與到達位置；跨世界保留狀態 | 地圖中尚未接上的其他互動機關另行移植 |
| 習題 | 240 題原注音題；乘法、個位數與兩位數加減法，不放回題池；不同錯選三次換注音題 | 注音採國字上方橫排；原題目選擇演算法的所有權重尚非逐項相同 |
| 存檔 | 地圖／位置／生命、背包、每世界生物、掉落與寶箱；學習進度獨立保存 | 沒有舊 Pyto v19 完整存檔匯入，也沒有跨裝置同步 |

主世界 259 個快照實例不是最終完整配置：原版在自訂生物加入前寫入快照，因此本次以目前 metadata 重建明確出生點，再合併編輯器放置點。其他地圖部分快照 revision 與地圖不同，自然生成位置保留作為移植基底，細節記在 `docs/gameplay-import.json`。

## 更新與存檔

- 維持同一專案名稱／iOS Bundle ID，沿用前一版的 Windows／iOS 使用者資料位置。
- 第一次執行 0.2.0，如果沒有新存檔，会讀取第一階段的地圖／位置；新進度寫入 `user://progress_v2.json`，不覆寫 `save_v1.json`。
- 新進度備份為 `progress_v2.json.bak`。學習進度是 `study_v1.json` 與 `.bak`，不會因讀取遊戲位置存檔而倒退。
- 沒有 iCloud 同步。iPhone、iPad、Xogot 與獨立 App 各自擁有資料區。
- 原始 Pyto ZIP 與第一階段 ZIP 均未修改；更換開發專案前仍可保留前一版資料夾。

## 驗證與限制

Windows Godot 4.5.1 已實際匯入、執行、擷取畫面並通過：

- 原 9 地圖共 117,639 格地形比對與原有移動／碰撞測試。
- 所有生物與自訂素材引用、目前編輯器放置點、240 題注音題庫驗證。
- 鐵劍傷害／冷卻、敵人傷害、死亡掉落、重生、寶箱防重領、跨圖與磁碟存檔。
- 不重複題池、錯答不計分、舊按鈕 token 防重複提交、錯選換題、待答题恢复、完成後才解鎖、答題暫停遊戲。

實際畫面：`docs/phase2-world.png`、`docs/phase2-math.png`、`docs/phase2-zhuyin.png`。

**GitHub Actions、iOS IPA 與 iPhone／iPad 實機仍尚未跑過。** 工作流程已加入第二階段測試；未把 Windows 通過當成真機通過。隔離測試環境依然有 Windows 根憑證庫讀取提示，離線玩法測試沒有因此失敗。
