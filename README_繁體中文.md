# PytoRPG Godot 0.5.0 / Phase5

本版接續 Phase4，補上可操作的工具／魔法／武器切換、準心、原版投射物和 Boss 招式。它仍不是原 FIX131 全功能等價版本；請看 [逐項驗收與差異](docs/Phase5移植驗收.md)。Phase4 原資料夾保留，本版放在另一個資料夾。

## 開啟

解壓縮，在 Godot 4.5.1 匯入本資料夾的 `project.godot`，按 F5。開始畫面可新開、載入、調整設定，或進入兩個編輯器。Windows 鍵盤及滑鼠可直接測試。保持相同專案名稱與使用者資料位置時，原 Godot 存檔可續用；此版保存新增的動作模式、工具、魔法、魔力、砍除植物及局部元素狀態。

## 操作

| 按鍵 | 功能 |
|---|---|
| A / D 或 ← / → | 移動，含加減速 |
| Space / Shift | 跳躍／翻滾 |
| C / Z / ↑ | 蹲下／趴下／站起；蹲走停下維持蹲姿 |
| ↑ / ↓ | 梯子上下；平台上按 ↓ 下落 |
| 1 / 2 / 3 | 武器／魔法／工具模式 |
| Tab | 循環切換動作模式 |
| T | 鐵鎬 → 斧頭 → 鉤爪，並進入工具模式 |
| R | 火球 → 水球 → 冰球 → 電球，並進入魔法模式 |
| V | 循環已持有、可使用的武器 |
| 滑鼠移動 | 調整準心方向 |
| U / I / O / K 或數字鍵盤 4 / 8 / 6 / 2 | 左／上／右／下瞄準，支援斜向 |
| J | 依目前模式執行動作；武器、魔法按住蓄力，放開施放；採集可按住連續使用 |
| Q | 選取鉤爪並射出；再次按 Q 收回；跳躍或換模式解除附著 |
| F / E | 使用目前採集工具／互動 |

畫面上方有可點選的模式與循環按鈕，右側圓形搖桿負責瞄準，右下「動作」按鈕執行目前模式。搖桿放開仍保留方向；切換模式會取消尚未釋放的蓄力。工具、魔法與武器名稱會顯示在生命／魔力列。K 已改作向下瞄準，翻滾請用 Shift。

## 建議先進入試驗場

「探索地點…」→「工具與戰鬥試驗場」，或地圖選單選 `control_lab`。這是額外的 Godot 測試地圖，不會取代原有九個世界。

1. 向右靠近兩棵樹，T 選斧頭、瞄準樹幹、按 J。木材與樹葉掉落後靠近拾取。
2. T 選鐵鎬，瞄準腳下或側邊、按住 J。橫向挖整格，上下挖裸露地面時逐層移除；石頭需要累積兩次命中。挖完保留背牆。
3. 對上方石台瞄準，Q 飛鉤；鉤爪會飛出、附著、收繩，第二次 Q 收回。需背包內有鉤爪，正常新遊戲已有。
4. 背包 →「開發測試武器」領取目前 20 種武器。1 選武器模式、V 或裝備選單切換，測試能量弓、雷射、溜溜球、陀螺、火箭、TNT、無人機與六種 Boss 武器。
5. 2 選魔法，R 切種類；J 蓄力少於 0.5 秒為 1 級、0.5 至未滿 1 秒為 2 級、1 秒起為 3 級。魔力會回復，冰球耗魔按 1／3／5 倍，其餘按 1／2／6 倍。
6. 向右有灰狼與首領。試驗場設為受擊後反擊；它們不是原世界新增的自動刷怪。
